# Counter App

This is a simple React Counter Application built using functional components and hooks.

## 🚀 Features
- Increment the counter
- Decrement the counter
- Reset the counter to zero

## 🛠️ Technologies Used
- React
- JavaScript (ES6)
- CSS

## 📚 Concepts Used
- useState Hook
- Functional Components
- Event Handling

## ▶️ How to Run
1. Install dependencies:
   npm install

2. Start development server:
   npm run dev

## 📌 Description
This project demonstrates basic state management in React using the useState hook. It updates the UI dynamically based on user interaction.
