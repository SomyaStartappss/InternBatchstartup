# 📝 To-Do App (JavaScript)

A simple and interactive To-Do application built using HTML, CSS, and JavaScript.

---

## 🚀 Features

* ➕ Add new tasks
* 📅 Set due date for each task
* ✔️ Mark tasks as completed
* ❌ Delete tasks
* 💾 Persistent storage using localStorage
* 🔄 Tasks remain saved even after page reload

---

## 🧠 Concepts Used

* DOM Manipulation
* Event Handling
* Arrays & Objects
* localStorage (getItem, setItem)
* JSON.stringify & JSON.parse

---

## 📂 Project Structure

* index.html → Structure of the app
* style.css → Styling
* script.js → Logic & functionality

---

## ⚙️ How It Works

1. User enters task and date
2. Task is stored as an object in an array
3. Array is saved in localStorage
4. On page load, data is fetched and displayed
5. User can mark tasks complete or delete them

---

## 💡 Example Task Object

```js
{
  text: "Complete project",
  date: "2026-04-07",
  done: false
}
```
