📘 Dark / Light Mode Toggle
📌 Overview

This project allows users to switch between Dark Mode and Light Mode using a toggle button. The selected theme is saved so that it remains the same even after refreshing the page.

⚙️ Features
Switch between dark and light theme
Saves user preference
Theme remains after page reload
🧠 Concept

The project uses JavaScript to change the theme by adding or removing a class from the page.
It uses localStorage to store the selected theme, so the browser remembers the user’s choice.

🎨 Role of CSS

CSS is responsible for changing the appearance of the page when the theme changes.

📌 Conclusion

This project demonstrates how to improve user experience by saving preferences and dynamically updating the UI using JavaScript.
